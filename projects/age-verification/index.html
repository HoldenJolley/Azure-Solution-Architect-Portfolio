SECURITY & PRIVACY REFERENCE ARCHITECTURE

Privacy-Preserving AI Age Assurance

A production-oriented Azure landing zone for bring-your-own AI age models. Images are encrypted on the client, remain ciphertext through the edge and gateway, are decrypted only in isolated inference memory, and are never intentionally stored.

PRIVACY CONTRACT

Plaintext exists only where it must.

◇

Encrypted before upload

The browser re-encodes the frame, generates a one-time AES-256-GCM key, and encrypts the image before it leaves the device. TLS provides an additional transport layer.

▦

Private inference

Front Door Premium reaches a private Azure Container Apps environment over Private Link. The gateway never decrypts the photograph; only the private inference process can unwrap the session key.

▤

No image retention

No image datastore is provisioned. Plaintext, ciphertext, embeddings, tensors, raw age estimates, and session keys are prohibited from logs and persistent application storage.
