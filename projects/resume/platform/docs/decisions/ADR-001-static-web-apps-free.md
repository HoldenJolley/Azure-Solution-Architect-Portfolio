# ADR-001 — Azure Static Web Apps Free

**Status:** Accepted

## Decision
Use Azure Static Web Apps Free as the portfolio hosting platform.

## Rationale
The workload is entirely static. The Free plan supplies the capabilities the portfolio requires—global static delivery, HTTPS, custom domains, GitHub integration, and preview environments—without a recurring Azure hosting charge within quota.

## Consequence
There is no SLA and several advanced networking features are unavailable. Those limitations are accepted for this personal portfolio.
