ARCHITECTURE

Use less Azure on purpose.

The design deliberately avoids App Service, Functions, databases, Azure DNS, paid CDN services, and a dedicated observability stack because this workload does not require them. GitHub is the source of truth, GitHub Actions handles deployment, and Azure Static Web Apps serves the static site globally.

Free-tier hostingAzure Static Web Apps Free with documented quota guardrails.

RecoveryVersion control + revert/redeploy; no stateful data to restore.
TRADEOFFS

Free is a design choice, not a claim of enterprise SLA.

The Free plan is appropriate because this is a personal portfolio. The architecture documents explicit triggers for moving to Standard if bandwidth, domain count, private networking, preview capacity, or availability requirements change.
